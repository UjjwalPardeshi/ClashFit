# Baseline profile — what to compile ahead of time.
#
# profileinstaller has been a dependency of this app for a while with nothing to install. Without
# a profile in this file the library is dead weight: it ships, it runs, and it has no rules to
# apply. With one, ART compiles these methods at install time instead of interpreting them on the
# first run, which is where a cold start and the first scroll spend most of their budget.
#
# The rules use AGP's wildcard form, so they survive a rename or a refactor. An entry that does not
# resolve is skipped silently rather than failing the build or the install, which is the right
# trade for a profile written by reading the code rather than by recording a device — the risk is
# a rule that does nothing, not a rule that breaks something.
#
# Flags: H = hot, S = startup, P = post-startup.
#
# This only takes effect in the minified release build. A debug build ignores it entirely, so the
# development loop is unaffected.
